# GWL_FCS30D 2022, 100°E–120°E, 30°N–50°N

[Open in data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/portolan-mirrors/gwl-fcs30d/gwl-fcs30d/2022/E100-E120_N30-N50/catalog.json) · [Source repository](https://github.com/nlebovits/gwl-fcs30d) · [Report a problem](https://github.com/nlebovits/gwl-fcs30d/issues) · [Hosting repository](https://source.coop/portolan-mirrors/gwl-fcs30d)

GWL_FCS30D wetland classes for 2022, tiles with an upper-left corner in 100°E–120°E, 30°N–50°N (bounds 100, 30, 120, 50). This catalog groups the producer's 5° tiles so no catalog lists more than 16 items.
