GWL_FCS30D wetland classes for 2022, tiles with an upper-left corner in 40°E–60°E, 30°N–50°N (bounds 40, 30, 60, 50). This catalog groups the producer's 5° tiles so no catalog lists more than 16 items.

The [collection README](../../README.md) describes the classes, the conversion and the citation.
